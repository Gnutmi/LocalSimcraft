    Quick Sim

    Paste your character export from the in-game SimulationCraft addon and run a single sim. The full HTML report opens in a new tab when it's done.

    Default 10,000. Raidbots Pro uses 25,000.
    Blank = use all CPU cores.

    Droptimizer

    Sim every potential drop from a raid or dungeon to see exactly how much DPS each upgrade is worth. Provide your profile and a list of candidate items in SimC gear-line format (one per line).

    Format: slot=,id=NNNN,bonus_id=A/B/C. Easiest source: copy item lines from a fresh addon export, or build them from Wowhead. Rings and trinkets are auto-tested in both slots.
    Per profileset.

    Top Gear

    Find the best piece in your bags for each slot. Tick "Show Bag Items" in the SimC addon before exporting — this picks up the commented bag-item lines and tests each as a swap.
